# ODETARI

An unofficial fan-made website dedicated to ODETARI.

The project brings together information about the artist, music, concerts, and fan photos in one place.

## Features

- User registration and login
- Personal user profiles
- Music discography
- Concert information and ticket bookings
- Photo gallery with user uploads
- Admin panel for managing concerts and gallery photos

## Technologies

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Docker

## Project Status

The project is currently under development. Responsive design and additional improvements are planned.

## Disclaimer

This is an unofficial fan-made project. It is not affiliated with or endorsed by ODETARI.
